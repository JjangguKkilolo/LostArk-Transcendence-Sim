## 검증이 필요한 사항

우선순위가 높은 순서다.

1. 전체 일반 정령의 정확한 한국어 명칭
2. 각 정령의 레벨별 공격 모양
3. 공격 위치별 일반·왜곡 석판 파괴 확률
4. 특수 타일 생성 시점과 대상 선정 규칙
5. 공격에 실패한 특수 타일의 유지 또는 소멸 규칙
6. 한 공격으로 여러 특수 타일이 파괴됐을 때 발동 순서
7. 왜곡 석판이 생성하는 석판의 위치 선정과 공간 부족 처리
8. 복제 후 동일 정령 자동 합성의 정확한 순서
9. 정령 교체 시 큐가 진행되는 정확한 방식
10. 신비 정령의 한국어 명칭, 범위, 확률
11. 부위·단계별 실제 보드
12. 부위·단계별 1·2·3등급 기준
13. 프로젝트가 재현할 정확한 패치 시점

## 구현 중 신뢰도 표시

규칙 데이터에는 출처와 신뢰도를 함께 기록한다.

```ts
type RuleConfidence = "VERIFIED" | "ESTIMATED" | "UNKNOWN";

type SourcedValue<T> = {
  value: T;
  confidence: RuleConfidence;
  source?: string;
  note?: string;
};
```

`ESTIMATED` 또는 `UNKNOWN` 규칙으로 AI 성능을 최종 평가하지 않는다.
