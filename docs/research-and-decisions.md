## 검증이 필요한 사항

우선순위가 높은 순서다.

1. 전체 일반 정령의 정확한 한국어 명칭
   - 일반 10종, 신비 2종을 당시 시뮬레이터 구현에서 확인
   - 업화/화염폭발의 자료별 표현 차이만 추가 검증
2. 각 정령의 레벨별 공격 모양
   - 시뮬레이터 ver 1.8.0 구현값 기록 완료
   - 실제 플레이 영상 또는 원본 표와 교차 검증 필요
3. 공격 위치별 일반·왜곡 석판 파괴 확률
   - 인벤 2023-09-27 최종 수정표와 시뮬레이터 구현의 일치 확인
   - 벼락의 파괴 수 범위는 확인, 파괴·재생의 결합 추첨 방식은 추가 검증
4. 특수 타일 생성 시점과 대상 선정 규칙
   - 시뮬레이터 ver 1.8.0 구현값 기록 완료
   - 매 턴 기존 특수 타일 정리 후 일반 석판 하나를 특수 타일로 변경
   - 생성 확률은 공식 공개 요약과 시뮬레이터 사이의 반올림 차이 추가 검증
5. 공격에 실패한 특수 타일의 유지 또는 소멸 규칙
   - 턴 처리 후 일반 석판으로 돌아가는 구현 확인
   - 실제 플레이 영상으로 전환 시점 교차 검증 필요
6. 한 공격으로 여러 특수 타일이 파괴됐을 때 발동 순서
   - 정상 보드에서는 특수 타일 최대 1개라는 불변조건을 확인
   - 우리 엔진은 여러 개가 입력되면 검증 오류로 처리
7. 왜곡 석판이 생성하는 석판의 위치 선정과 공간 부족 처리
   - 왜곡 타격 1회당 무작위 빈칸 최대 3개를 일반 석판으로 복구
   - 공간 부족 시 가능한 빈칸만 복구하는 시뮬레이터 구현 확인
   - 여러 왜곡 석판 동시 타격 시 3개씩 누적
   - 정화·세계수의 공명은 실제 파괴하며 재생성 없음
8. 복제 후 동일 정령 자동 합성의 정확한 순서
   - 반대쪽 정령 복제 후 사용 슬롯에 대기 0을 먼저 배치
   - 갱신된 활성 2장이 같을 때만 자동 합성
9. 정령 교체 시 큐가 진행되는 정확한 방식
   - 사용·교체 모두 선택 슬롯에 대기 0을 배치
   - 대기열을 전진시키고 끝에 새 일반 정령을 생성
   - 교체는 소환 횟수를 쓰지 않고 교체 가능 횟수만 1 소모
   - 카드 갱신 후 동일 정령 합성을 연쇄 판정
10. 신비 정령의 한국어 명칭, 범위, 확률
11. 부위·단계별 실제 보드
   - 무기·방어구 6부위 × 7단계의 42개 보드 데이터 추출
   - 단계별 크기, 활성 영역 모양, 왜곡 석판 좌표 기록
   - 전체 실제 게임 화면과의 최종 시각 대조는 추가 가능
12. 부위·단계별 1·2·3등급 기준
   - 부위 3그룹과 단계 구간별 3등급 기준선 기록
   - 2등급은 기준선 +1, 1등급은 +2~+3, 이후 0등급
13. 프로젝트가 재현할 정확한 패치 시점
   - 2024-07-24 완화 패치 이후부터 2024-12-18 개편 이전으로 확정
   - 기준 시뮬레이터 ver 1.8.0(2024-10-07)과 일치
   - 2024-12-18 이후의 가호 최대 8단계 및 개편 규칙은 제외

## 구현 중 신뢰도 표시

규칙 데이터에는 출처와 신뢰도를 함께 기록한다.

```ts
type RuleConfidence =
  | "VERIFIED"
  | "SIMULATOR_REFERENCE"
  | "ESTIMATED"
  | "UNKNOWN";

type SourcedValue<T> = {
  value: T;
  confidence: RuleConfidence;
  source?: string;
  note?: string;
};
```

`SIMULATOR_REFERENCE`는 공식 설명에서 확인할 수 없는 세부 동작을 기준 시뮬레이터와
같게 재현한다는 뜻이다. `ESTIMATED` 또는 `UNKNOWN` 규칙으로 AI 성능을 최종
평가하지 않는다.
