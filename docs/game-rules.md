# 게임 규칙

## 대상 규칙 버전

이 프로젝트는 로스트아크의 **개편 전 고대 석판 파괴 방식**을 재현한다. 이후 도입된
고대 석판 정화 방식과 혼합하지 않는다.

내부 식별자 예:

```ts
const RULESET_ID = "lostark-transcendence-classic";
```

현재 기준 규칙 버전은 `classic-2024-07-24`이며, 2024-12-18 개편 전까지의
클래식 규칙을 뜻한다.

## 성공과 등급

- 정령을 사용하여 필수 고대 석판을 모두 파괴하면 성공한다.
- 왜곡 석판은 성공을 위해 반드시 파괴할 필요가 없다.
- 적은 정령 소환 횟수로 성공할수록 높은 초월 등급을 얻는다.
- 부위 및 초월 단계마다 등급별 소환 횟수 기준이 다르다.
- 행동 턴과 등급 계산용 정령 소환 횟수는 별개의 값이다.

```ts
type ClearGrade = 0 | 1 | 2 | 3;

type GradeThresholds = {
  grade3: number;
  grade2: number;
  grade1: number;
};
```

## 석판

### 일반 고대 석판

- 성공을 위해 파괴해야 하는 기본 목표다.
- 남아 있는 일반 고대 석판이 없으면 성공을 판정한다.

### 왜곡된 석판

- 성공 조건에서는 제외된다.
- 비엘조윈 정령의 타격이 성공하면 왜곡 석판은 남고 일반 석판을 최대 3개 복구한다.
- 정화와 세계수의 공명은 왜곡 석판을 실제로 파괴하고 일반 석판을 복구하지 않는다.
- 일반 비엘조윈 정령의 3레벨은 왜곡 석판을 무시한다.
- 복구 위치와 공간 부족 처리는 시뮬레이터 기준 규칙을 따른다.

### 지속되는 정령 석판(특수 타일)

정령을 소환할 때 남은 석판 하나에 6종 중 하나의 보조 효과가 부여된다.
해당 석판이 파괴되면 효과가 발동한다.

| 효과 | 규칙 |
|---|---|
| 재배치 | 남아 있는 모든 석판의 위치를 다시 배치한다. |
| 축복 | 이번 정령 소환 횟수가 증가하지 않는다. |
| 추가 | 정령 교체 가능 횟수가 1 증가한다. |
| 신비 | 사용하지 않은 반대쪽 정령을 유적의 신비 중 하나로 변경한다. |
| 강화 | 사용하지 않은 반대쪽 정령을 1단계 강화한다. |
| 복제 | 사용하지 않은 반대쪽 정령을 방금 사용한 정령과 같게 변경한다. |

신비 정령은 `Outburst`와 `World Tree's Resonance`로 확인되며, 정확한 한국어 명칭과
효과 수치는 검증 후 확정한다.

## 정령

### 선택과 큐

- 현재 정령 후보 2개 중 하나를 선택해 사용한다.
- 다음 정령을 미리 볼 수 있다.
- 정령을 사용하면 큐가 진행된다.
- 제한된 횟수만큼 정령을 교체할 수 있다.

```ts
type SpiritQueue = {
  choices: [Spirit, Spirit];
  preview: Spirit[];
  rerollsRemaining: number;
};
```

### 합성과 강화

- 현재 두 정령이 같으면 자동으로 합성되어 강화된다.
- 정령은 최대 두 번 강화된다.
- 강화 시 범위, 일반 석판 파괴 확률 또는 왜곡 석판 상호작용이 달라질 수 있다.
- 최고 단계 정령과 신비 정령은 강화 타일의 영향을 받지 않는다.

### 정령별 차이

- 공격 범위와 모양
- 범위 내 각 석판의 파괴 확률
- 선택 가능한 중심 위치
- 강화 단계별 범위와 확률
- 왜곡 석판을 파괴하거나 보호하는 방식

현재 자료에서 확인되는 일반 정령군:

- 업화
- 대폭발
- 해일
- 충격파
- 지진
- 폭풍우
- 벼락
- 낙뢰
- 용오름
- 정화

일반 정령 10종과 신비 정령 2종의 전체 목록, 레벨별 범위와 확률은
[정령 목록과 공격 형태](./rules/spirits.md)에 기록한다. 일부 공식 한국어 명칭은
추가 검증 대상이다.

## 정령 교체

- 현재 정령이 불리할 때 교체권을 소비해 변경할 수 있다.
- 특수 타일 `추가`로 교체 횟수를 회복할 수 있다.
- 엘조윈의 가호 단계가 교체 횟수에 영향을 줄 수 있다.
- 공격과 교체는 모두 AI가 평가해야 하는 합법 행동이다.

## 엘조윈의 가호

반복 실패에 따른 완화 시스템이다.

확인된 고전 규칙:

- 장비 부위와 초월 단계별로 별도 누적된다.
- 가호 단계에 따라 왜곡 석판 일부가 일반 석판으로 변경된다.
- 정령 교체 가능 횟수가 증가한다.
- 패치 시점에 따라 발동 조건과 최대 단계 효과가 달라졌다.

첫 버전은 가호 0~10을 수동 설정할 수 있도록 초기 상태 구조에 포함하며 기본값은
0으로 둔다. 누적 실패에 따라 가호가 자동으로 오르는 장기 진행은 이후 기능이다.

## 한 행동의 규칙 처리 순서

구현의 단일 기준은 [턴 상태 전이 통합 명세](./rules/turn-state-machine.md)다.
요약 순서는 행동 검증, 비용 예약, 전체 타격 추첨, 왜곡 복구, 정령 고유 후속 효과,
파괴된 특수 효과, 특수 석판 갱신, 카드 큐·합성, 성공·등급 판정이다.

정상 보드에는 특수 석판이 최대 하나이므로 복수 특수 효과의 임의 발동 순서를 만들지
않는다. 이 불변조건을 어긴 입력은 엔진 오류로 처리한다.

## 원작 요소 중 대전에서 단순화할 항목

첫 버전에서 제외:

- 정령 사용 골드
- 초월 중단 및 유적 복원 재료
- 장비 능력치 상승
- 부위별 누적 초월 효과
- 레이드 선행 해금 조건

대전용 대체 기능:

- 기권
- 동일 초기 보드 재도전
- 새로운 시드로 시작
- 리플레이
