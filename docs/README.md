# 사람 vs 초파고 프로젝트 문서

> 상태: 초기 설계 초안  
> 대상 규칙: 개편 전 고대 석판 파괴 방식  
> 주의: 정령별 수치와 일부 연쇄 규칙은 검증 중

이 디렉터리는 개편 전 로스트아크 장비 초월의 석판 파괴 미니게임을 바탕으로,
사람과 AI가 동일한 초기 조건에서 각자 독립된 확률 결과를 받아 대결하는 웹 게임의
기획·규칙·기술 설계를 관리한다.

## 프로젝트 기준

- 대상 규칙은 **개편 전 고대 석판 파괴 방식(classic ruleset)** 이다.
- 플레이어와 AI는 동일한 초기 보드에서 시작한다.
- 실제 확률 결과는 각 게임 인스턴스의 독립된 난수를 사용한다.
- 규칙 엔진은 UI, 애니메이션, AI 알고리즘과 분리한다.
- 규칙의 정확성이 확인되지 않은 항목은 추측으로 고정하지 않는다.
- 저장 데이터에는 프로그램 스키마 버전과 초월 규칙 버전을 함께 기록한다.
