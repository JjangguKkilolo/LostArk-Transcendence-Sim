# LostArk Transcendence Sim

개편 전 로스트아크 장비 초월을 바탕으로 사람과 초파고가 동일한 초기 조건에서
독립된 확률 결과로 대결하는 웹 게임 프로젝트다.

## 현재 구현

- 규칙 버전 `classic-2024-07-24`
- 순수 TypeScript 게임 코어 기반
- 재현 가능한 시드 난수
- 6부위 × 7단계의 보드 정의 42개
- 보드 모양과 왜곡 석판 데이터 검증
- 엘조윈의 가호 0~10단계 초기화
- 초월 등급 계산
- 일반 정령 10종의 등장 가중치
- 활성 정령 2장과 미리보기 3장
- 정령 사용·교체에 따른 큐 진행
- 최대 3레벨 자동 연쇄 합성
- 업화·낙뢰·용오름·충격파 공격 범위
- 대폭발·지진·폭풍우·해일 선형 공격 범위
- 레벨별 일반·왜곡 석판 파괴 확률 계획
- 선형 공격의 거리당 15% 감소와 10% 하한
- 정화·분출·세계수의 공명 공격 범위
- 벼락의 단일 타격과 레벨별 추가 파괴·석판 재생성 추첨
- 공격 결과·왜곡 복구·벼락 후속 효과의 순차적 보드 반영
- 특수 석판 6종의 가중치·파괴 효과·한 턴 수명과 재배치
- 게임 생성·합법 행동·정령 사용·교체·완료 등급의 통합 상태 전이
- 동일 초기 상태·선택 잠금·독립 난수·라운드 기록을 갖춘 사람 대 초파고 대전
- 엘조윈 계열의 왜곡 석판 복구 없는 파괴
- 비엘조윈 정령의 왜곡 석판 중심 선택 제한
- 좌표순 시드 기반 공격 결과 추첨

실제 초파고 추천 점수와 탐색 알고리즘은 다음 구현 단계다.

## 개발 명령

Node.js 22.6 이상이 필요하다.

```bash
npm install
npm run typecheck
npm test
```
