# 왜곡된 고대 석판

> 조사 상태: 인벤 원문·범위표·시뮬레이터 구현 교차 확인
> 대상: 개편 전 고대 석판 파괴 방식
> 기준 구현: 초월 시뮬레이터 ver 1.8.0 (2024-10-07)

## 조사 결과 요약

- 왜곡된 고대 석판은 일반 석판과 다른 실패 유발 요소다.
- 일반 석판을 모두 파괴하면 성공하며 왜곡 석판은 성공 조건에 포함되지 않는다.
- 비(非)엘조윈 정령이 왜곡 석판을 타격하면 왜곡 석판은 남고, 파괴된 위치에
  일반 석판을 최대 3개 재생성한다.
- 정화와 세계수의 공명처럼 엘조윈 계열인 정령은 왜곡 석판을 실제로 파괴하며
  일반 석판을 재생성하지 않는다.
- 일반 정령의 최고 강화 단계는 범위 안의 왜곡 석판을 타격하지 않고 무시한다.

## 용어

자료에 따라 다음 표현이 혼용된다.

- 왜곡된 고대 석판: 게임 및 규칙표의 정식 표현
- 왜곡된 석판: 줄임말
- 오염된 석판, 보라 석판: 커뮤니티 표현

프로젝트 내부 명칭은 `DISTORTED`로 통일한다.

## 공격 중심 선택 제한

- 비엘조윈 계열 정령은 왜곡 석판을 공격 중심으로 선택할 수 없다.
- 엘조윈 계열인 정화와 세계수의 공명만 왜곡 석판을 중심으로 선택할 수 있다.
- 비엘조윈 정령의 범위에 왜곡 석판이 포함되는 것은 허용되며, 이때 아래 복구 또는
  무시 규칙을 적용한다.

기준 시뮬레이터는 비엘조윈 정령이 왜곡 석판을 중심으로 선택하면 공격 범위 전체를
0으로 반환한다. 우리 엔진은 의미 없는 행동이 실행되지 않도록 합법 행동 생성
단계에서 해당 목표를 제외한다.

## 일반 정령으로 타격

비엘조윈 정령의 공격 판정이 왜곡 석판에 성공하면 다음과 같이 처리한다.

1. 왜곡 석판은 제거하지 않는다.
2. 재생성 예정 수를 3 증가시킨다.
3. 현재 보드에서 파괴된 빈칸을 수집한다.
4. 빈칸을 무작위로 섞는다.
5. 최대 3개의 빈칸을 일반 석판으로 되돌린다.

공격 한 번으로 왜곡 석판 여러 개를 타격하면 각 석판마다 3개씩 누적한다.

```ts
requestedRestoreCount = hitDistortedTileCount * 3;
actualRestoreCount = Math.min(requestedRestoreCount, emptyPlayableCells.length);
```

### 빈칸이 부족한 경우

- 빈칸이 3개 이상이면 중복 없이 3곳을 선택한다.
- 빈칸이 1~2개라면 존재하는 빈칸만 모두 복구한다.
- 빈칸이 없다면 아무것도 생성하지 않는다.
- 기존 일반·왜곡·특수 석판을 덮어쓰지 않는다.
- 보드 바깥의 비활성 좌표에는 생성하지 않는다.

빈칸 부족 처리는 시뮬레이터 구현에서 확인했으며, 인벤 범위표에는 단순히
“랜덤한 위치에 석판 3개 생성”으로 설명되어 있다.

## 처리 시점

일반 석판 재생성은 해당 정령의 전체 파괴 판정이 끝난 뒤 처리한다.

따라서 새로 생성된 석판은 같은 범위 공격에 다시 맞지 않는다. 한 번의 정령 사용은
다음처럼 원자적으로 계산한다.

```text
전체 타격 추첨
→ 일반·특수 석판 제거
→ 왜곡 타격 수 집계
→ 일반 석판 재생성
→ 후속 특수 효과
```

벼락의 추가 무작위 효과는 기준 시뮬레이터에서 왜곡 석판 재생성 뒤에 실행된다.
다만 벼락 자체는 왜곡 석판을 공격 대상으로 삼지 않는다.

## 엘조윈 계열 예외

| 정령 | 왜곡 석판 처리 |
|---|---|
| 정화 | 표시된 파괴 확률대로 실제 파괴, 석판 재생성 없음 |
| 세계수의 공명 | 범위 안 왜곡 석판을 100% 파괴, 석판 재생성 없음 |

엘조윈 계열 여부는 개별 공격 모양과 분리된 규칙 속성으로 관리한다.

```ts
type DistortedInteraction =
  | "TRIGGER_RESTORE"
  | "DESTROY_WITHOUT_RESTORE"
  | "IGNORE";
```

## 강화 단계별 처리

| 정령 종류 | 1레벨 | 2레벨 | 3레벨 |
|---|---|---|---|
| 일반 비엘조윈 정령 | 범위 확률로 타격 시 재생성 | 100% 타격 시 재생성 | 왜곡 석판 무시 |
| 정화 | 범위 확률로 실제 파괴 | 100% 실제 파괴 | 확대된 범위로 100% 실제 파괴 |
| 세계수의 공명 | 해당 없음 | 해당 없음 | 해당 없음 |

세계수의 공명은 강화되지 않는 신비 정령이며 기본 상태에서 범위 전체가 100%다.

## 성공 조건과 판정 순서

초월 성공 조건은 `일반 석판이 0개`인 것이다. 왜곡 석판은 남아 있어도 성공한다.

```ts
function isComplete(board: Board): boolean {
  return board.playableCells().every(cell =>
    cell === null ||
    cell.kind === "DISTORTED"
  );
}
```

왜곡 타격으로 일반 석판이 재생성됐다면 그 석판도 다시 제거해야 하므로 성공하지
않는다. 성공 판정은 재생성과 특수 효과 처리가 끝난 뒤 수행한다.

## 엘조윈의 가호와의 관계

기준 시뮬레이터에서 엘조윈의 가호는 게임 시작 시 설정된 수만큼의 왜곡 석판을
무작위로 골라 일반 석판으로 변경한다. 이는 정령 공격 중 발생하는 정화와 별도다.

가호 단계별 실제 적용 수치와 교체 횟수 보정은 별도 조사 문서에서 확정한다.

## 엔진 이벤트 초안

```ts
type DistortedTileEvent =
  | {
      type: "DISTORTED_HIT";
      position: Position;
      restoreRequested: 3;
    }
  | {
      type: "TILES_RESTORED";
      positions: Position[];
    }
  | {
      type: "DISTORTED_DESTROYED";
      position: Position;
      bySpiritId: SpiritId;
    }
  | {
      type: "DISTORTED_IGNORED";
      position: Position;
    };
```

왜곡 타격 애니메이션과 석판 재생성 애니메이션을 별도 이벤트로 나누면 결과 계산을
바꾸지 않고도 연출 속도를 조정할 수 있다.
