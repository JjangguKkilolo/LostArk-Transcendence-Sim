# LostArk Transcendence Sim

개편 전 로스트아크 장비 초월을 바탕으로 사람과 초파고가 동일한 초기 조건에서
독립된 확률 결과로 대결하는 웹 게임 프로젝트다.

## 현재 구현

- 규칙 버전 `classic-2024-07-24`
- 순수 TypeScript 게임 코어 기반
- 재현 가능한 시드 난수
- 6부위 × 7단계의 보드 정의 42개
- 보드 모양과 왜곡 석판 데이터 검증
- 엘조윈의 가호 0~10단계 초기화
- 초월 등급 계산
- 일반 정령 10종의 등장 가중치
- 활성 정령 2장과 미리보기 3장
- 정령 사용·교체에 따른 큐 진행
- 최대 3레벨 자동 연쇄 합성
- 업화·낙뢰·용오름·충격파 공격 범위
- 대폭발·지진·폭풍우·해일 선형 공격 범위
- 레벨별 일반·왜곡 석판 파괴 확률 계획
- 선형 공격의 거리당 15% 감소와 10% 하한
- 정화·분출·세계수의 공명 공격 범위
- 벼락의 단일 타격과 레벨별 추가 파괴·석판 재생성 추첨
- 공격 결과·왜곡 복구·벼락 후속 효과의 순차적 보드 반영
- 특수 석판 6종의 가중치·파괴 효과·한 턴 수명과 재배치
- 게임 생성·합법 행동·정령 사용·교체·완료 등급의 통합 상태 전이
- 동일 초기 상태·선택 잠금·독립 난수·라운드 기록을 갖춘 사람 대 초파고 대전
- 기대 파괴·복구·왜곡 위험·특수 타격을 평가하는 초파고 휴리스틱 추천
- 독립 샘플 시드·휴리스틱 롤아웃·취소·시간 한도를 지원하는 Monte Carlo 초파고
- 선택 순위·판단 손실과 기대값 대비 실제 결과를 분리하는 판단·운 분석
- 사람과 초파고의 두 보드를 동시에 보여주는 반응형 웹 게임 화면
- 정령 선택·목표 지정·교체와 초파고 추천 근거 표시
- 타격·파괴·복구·특수 효과를 단계별로 묶어 재생하는 애니메이션 타임라인
- 한쪽이 먼저 종료되어도 상대편 시뮬레이션을 끝까지 진행하는 대전 흐름
- 엘조윈 계열의 왜곡 석판 복구 없는 파괴
- 비엘조윈 정령의 왜곡 석판 중심 선택 제한
- 좌표순 시드 기반 공격 결과 추첨

현재 웹 화면은 휴리스틱 초파고를 사용한다. 다음 단계에서는 게임 설정 선택과
Monte Carlo 추천을 웹 워커에 연결해 계산 중에도 애니메이션과 입력이 부드럽게
유지되도록 확장한다.

## 개발 명령

Node.js 22.6 이상이 필요하다.

```bash
npm install
npm run typecheck
npm test
npm run dev
npm run build
```
