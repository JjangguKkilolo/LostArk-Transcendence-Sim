# 제품 개요

## 한 줄 정의

동일한 초월 판에서 사람과 초파고가 서로의 선택을 보지 않고 행동한 뒤, 각자의 독립된
확률 결과를 받아 판단과 운을 겨루는 애니메이션 웹 게임이다.

## 핵심 재미

이 게임은 단순히 AI의 추천을 따라 하는 계산기가 아니다.

- 사람과 AI가 같은 출발점에서 서로 다른 선택을 한다.
- 같은 정령으로 같은 위치를 공격해도 확률 결과는 달라질 수 있다.
- 플레이어가 AI보다 좋은 판단을 했는지 비교할 수 있다.
- 좋은 판단을 하고도 운이 나빴는지, 나쁜 판단을 운으로 극복했는지 보여준다.
- 최종 승패뿐 아니라 판단 품질과 운의 정도를 함께 분석한다.

## 공정한 대전 조건

### 양쪽에 동일한 것

- 장비 부위와 초월 단계
- 최초 석판 배치
- 최초에는 특수 석판이 없는 상태
- 최초 정령 후보와 미리보기
- 가호 단계
- 소환 횟수 및 등급 기준
- 적용되는 규칙 버전

### 양쪽에서 독립적인 것

- 정령의 확률적 파괴 결과
- 왜곡 석판과 석판 복구 결과
- 특수 효과의 확률 결과
- 첫 턴 이후의 무작위 정령 결과
- 연쇄 효과 결과
- 플레이어와 AI의 행동 선택

## 한 턴의 대전 흐름

1. 플레이어가 정령과 목표 위치 또는 정령 교체를 선택한다.
2. 플레이어의 선택을 잠그고 아직 AI 선택을 공개하지 않는다.
3. AI가 자신의 보드 상태만 보고 행동을 계산한다.
4. 양쪽 행동을 동시에 공개한다.
5. 양쪽 정령 애니메이션을 재생한다.
6. 각 인스턴스의 독립 난수로 결과를 적용한다.
7. 파괴량, 남은 석판, 등급 가능성을 비교한다.
8. 양쪽 모두 종료되지 않았다면 다음 턴으로 이동한다.

```text
PLAYER_THINKING
  → AI_THINKING
  → REVEALING_ACTIONS
  → PLAYING_ANIMATIONS
  → COMPARING_RESULTS
  → 다음 턴 또는 FINISHED
```

AI는 플레이어의 선택이나 플레이어 보드의 확률 결과를 입력으로 받아서는 안 된다.

## 승패 기준

기본 비교 우선순위는 다음과 같다.

1. 초월 성공 여부
2. 획득한 초월 등급
3. 사용한 정령 소환 횟수
4. 남은 필수 석판 수
5. 동률

한쪽이 먼저 성공하더라도 같은 라운드의 반대쪽 행동까지 모두 해결한 후 결과를 비교한다.

## 결과 분석

결과 화면은 세 영역을 분리한다.

### 판단

- 선택 가능한 전체 행동 수
- 플레이어가 고른 행동의 AI 평가 순위
- 선택 당시 클리어 확률
- 최선 행동과의 확률 차이
- 누적 판단 손실

### 운

- 기대 파괴량
- 실제 파괴량
- 기대값 대비 편차
- 불리하거나 유리했던 확률 사건

### 최종 결과

- 성공 여부
- 초월 등급
- 정령 소환 횟수
- 남은 필수 석판
- 승자

예시:

```text
플레이어 승리

플레이어
- 7회 소환으로 성공
- 선택 품질: 상위 12%
- 기대 파괴량보다 +3

초파고
- 8회 소환으로 성공
- 선택 품질: 상위 1%
- 기대 파괴량보다 -4
```

## 제품 확장 방향

- AI 난이도: 무작위, 휴리스틱, Monte Carlo, 다중 턴 탐색
- 특정 시드 공유 및 같은 판 도전
- 리플레이
- 일일 도전
- 전적과 랭킹
- 플레이어 선택과 AI 선택 비교 히트맵
- AI가 선택한 이유 설명
- 인게임 화면 인식 기반 상태 입력
