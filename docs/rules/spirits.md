# 정령 목록과 공격 형태

> 조사 상태: 인벤 범위표·공개 확률·시뮬레이터 구현 교차 확인
> 대상: 개편 전 고대 석판 파괴 방식
> 이번 문서 범위: 정령 목록, 계열, 레벨별 공격 범위와 확률
> 기준 구현: 초월 시뮬레이터 ver 1.8.0 (2024-10-07)

## 신뢰도 기준

| 표기 | 의미 |
|---|---|
| 확정 | 공식 설명 또는 독립된 복수 자료에서 일치 |
| 유력 | 당시 정리 자료에서 확인됐지만 공식 세부 표가 없음 |
| 미확정 | 자료 간 명칭 불일치 또는 이미지 원문 추가 판독 필요 |

## 조사 결과 요약

- 일반 정령은 현재 자료상 10종으로 분류된다.
- 신비 타일을 통해 얻는 별도 정령은 2종으로 분류된다.
- 정령은 에페르니아, 실페리온, 그노시스, 운다트, 엘조윈 계열로 표시된다.
- 같은 정령이 합쳐지면 일반 → 강화 → 최고 강화의 3단계로 운용된다.
- 인벤의 2023-09-27 최종 수정 범위표와 공개된 웹 시뮬레이터 번들에서 레벨별
  범위·확률이 일치하는 것을 확인했다.
- 정령 등장 확률은 2024년 로스트아크 확률 공개 내용을 옮긴 인벤 자료와도 일치한다.

### 명칭 주의

- 일부 검색 이미지 설명에는 업화 대신 `화염폭발`이라는 표현이 나타난다.
- 영문 커뮤니티에서는 업화를 주로 `Hellfire`라고 부른다.
- `대폭발`과 신비 정령 `분출`의 영문 번역이 자료마다 혼동될 수 있다.
- 코드 ID는 규칙 검증 전까지 초안이며 저장 데이터의 영구 ID로 확정하지 않는다.

## 신비 정령

| 내부 ID 초안 | 한국어 명칭 | 계열 | 확인된 기본 형태 | 상태 |
|---|---|---|---|---|
| `OUTBURST` | 분출 | 운다트 | 선택한 일반 석판 1개를 파괴 | 구현 확인 |
| `WORLD_TREE_RESONANCE` | 세계수의 공명 | 엘조윈 | 중심과 상하좌우 2칸의 십자 9칸 | 구현 확인 |

신비 정령은 특수 타일 `신비`가 발동할 때 사용하지 않은 반대쪽 정령을 대체한다.
공식 영문 자료에서는 `Outburst`, `World Tree's Resonance`로 표현된다.

## 공통 공격 규칙

현재 확인된 일반적인 설명:

- 선택 지점은 범위 내 다른 지점과 다른 확률 규칙을 가질 수 있다.
- 다수의 범위형 정령은 선택 지점을 제외한 석판을 확률적으로 파괴한다.
- 정령 종류에 따라 공격 범위와 석판 파괴 확률이 다르다.
- 강화되면 범위 또는 파괴 확률이 상승한다.
- 강화 단계에서는 일반 고대 석판 파괴 확률이 100%가 되는 것으로 정리된 자료가 있다.
- 최고 강화 단계에서는 왜곡된 고대 석판을 무시하는 효과가 추가된 것으로 정리된 자료가 있다.
- 비엘조윈 계열 정령은 왜곡 석판을 공격 중심으로 선택할 수 없다.
- 정화와 세계수의 공명은 왜곡 석판을 중심으로 선택할 수 있다.

### 레벨별 확률

`d`는 선택점으로부터 해당 선을 따라 떨어진 칸 수다.

| 정령 | 1레벨 | 2레벨 | 3레벨 |
|---|---|---|---|
| 업화 | 중심 100%, 나머지 50% | 범위 전체 100% | 중심 100%, 일반 석판 100%, 중심 외 왜곡 0% |
| 대폭발 | 중심 100%, 나머지 `max(100%-15%×d, 10%)` | 범위 전체 100% | 중심 100%, 일반 석판 100%, 중심 외 왜곡 0% |
| 낙뢰 | 중심 100%, 상하좌우 50% | 범위 전체 100% | 일반 석판 100%, 왜곡 0% |
| 용오름 | 중심 100%, 대각선 네 칸 50% | 범위 전체 100% | 일반 석판 100%, 왜곡 0% |
| 충격파 | 중심 100%, 나머지 75% | 범위 전체 100% | 일반 석판 100%, 왜곡 0% |
| 지진 | `max(100%-15%×d, 10%)` | 범위 전체 100% | 일반 석판 100%, 왜곡 0% |
| 폭풍우 | `max(100%-15%×d, 10%)` | 범위 전체 100% | 일반 석판 100%, 왜곡 0% |
| 해일 | `max(100%-15%×d, 10%)` | 범위 전체 100% | 일반 석판 100%, 왜곡 0% |
| 정화 | 중심 100%, 좌우 50% | 가로 3칸 100% | 십자 5칸 100%, 왜곡도 타격 가능 |

벼락은 별도 규칙이다.

- 선택한 일반 석판은 100% 파괴하며 왜곡 석판은 선택할 수 없다.
- 이후 `-1` 또는 `0..2×레벨` 중 하나를 균등 추첨한다.
- `-1`이면 빈칸 하나에 일반 석판을 재생성한다.
- 0 이상이면 그 수만큼 무작위 일반 석판을 추가 파괴한다.
- 따라서 추첨 후보는 1레벨 `-1..2`, 2레벨 `-1..4`, 3레벨 `-1..6`이다.

인벤 범위표와 댓글에서도 기본 1칸 외 무작위 파괴 수가 1레벨 0~2칸,
2레벨 0~4칸, 3레벨 0~6칸이며 석판 0~1개가 생성될 수 있음을 확인했다.
다만 “추가 파괴와 재생성이 하나의 배타적 추첨인가, 별도의 두 추첨인가”는 표의
문구만으로 확정되지 않는다. 현재 시뮬레이터는 하나의 배타적 추첨으로 구현한다.

## 구현용 데이터 형식 초안

```ts
type SpiritId =
  | "HELLFIRE"
  | "GREAT_EXPLOSION"
  | "LIGHTNING"
  | "THUNDER_STRIKE"
  | "TORNADO"
  | "SHOCKWAVE"
  | "EARTHQUAKE"
  | "TIDAL_WAVE"
  | "RAINSTORM"
  | "PURIFY"
  | "OUTBURST"
  | "WORLD_TREE_RESONANCE";

type SpiritDefinition = {
  id: SpiritId;
  name: string;
  category: "NORMAL" | "MYSTERY";
  elementalLord: "EPHERNIA" | "SILPERION" | "GNOSIS" | "UNDART" | "ELZOWIN";
  levels: SpiritLevelDefinition[];
};

type SpiritLevelDefinition = {
  level: 1 | 2 | 3;
  targeting: TargetingRule;
  pattern: PatternCell[];
  specialRule?: SpiritSpecialRule;
};

type PatternCell = {
  offset: {
    row: number;
    column: number;
  };
  ancientDestroyChance: number;
  distortedDestroyChance: number;
};
```

## 다음에 확인해야 할 항목

각 정령의 1·2·3단계마다 다음 표를 완성해야 한다.

| 항목 | 상태 |
|---|---|
| 선택점을 기준으로 한 정확한 상대 좌표 | 인벤 최종 수정표와 구현 일치 |
| 일반 석판 파괴 확률 | 인벤 최종 수정표와 구현 일치 |
| 왜곡 석판 파괴 확률 | 인벤 최종 수정표와 구현 일치 |
| 선택점의 확정 파괴 여부 | 인벤 최종 수정표와 구현 일치 |
| 보드 바깥 범위 처리 | 자연스럽게 무시 |
| 빈 타일을 공격했을 때의 처리 | 벼락을 제외하면 효과 없음 |
| 방향 또는 회전 선택 가능 여부 | 미확정 |
| 비엘조윈 정령의 왜곡 중심 선택 금지 | 시뮬레이터 공통 타겟 함수 확인 |
| 벼락의 추가 타격 횟수 범위 | 인벤 표·댓글과 구현 일치 |
| 벼락의 파괴·재생 추첨 결합 방식 | 추가 검증 필요 |
| 최고 강화의 왜곡 석판 무시 규칙 | 인벤 최종 수정표와 구현 일치 |
