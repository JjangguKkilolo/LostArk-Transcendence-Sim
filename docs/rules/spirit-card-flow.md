# 정령 카드·대기열·합성 흐름

> 조사 상태: 인벤 공략·시뮬레이터 구현 교차 확인
> 대상: 개편 전 고대 석판 파괴 방식
> 기준 구현: 초월 시뮬레이터 ver 1.8.0 (2024-10-07)

## 조사 결과 요약

- 플레이어가 선택할 수 있는 활성 정령은 2장이다.
- 앞으로 등장할 정령 3장을 미리 볼 수 있다.
- 정령을 사용하거나 교체하면 해당 슬롯에 대기열 첫 정령이 들어온다.
- 대기열은 한 칸 앞으로 이동하고 끝에 새 무작위 정령이 추가된다.
- 활성 슬롯의 정령 두 장이 같은 종류면 자동으로 합성된다.
- 합성으로 대기열 카드가 활성화된 뒤 다시 같은 정령이 만나면 연쇄 합성된다.
- 강화·복제·신비 특수 석판은 사용하지 않은 반대쪽 정령에 먼저 적용되고,
  그 뒤 사용한 슬롯에 대기열 첫 카드가 들어온다.

## 카드 영역

```ts
type SpiritHand = {
  active: [SpiritCard, SpiritCard];
  previewQueue: [SpiritCard, SpiritCard, SpiritCard];
};
```

화면에서는 총 5장을 유지한다.

```text
[활성 0] [활성 1] | [대기 0] [대기 1] [대기 2]
```

- 활성 0·1: 이번 턴에 선택하거나 교체할 수 있다.
- 대기 0: 다음에 활성 슬롯으로 들어올 정령이다.
- 대기 1·2: 그 이후 순서이며 플레이어와 AI 모두 볼 수 있다.
- 새 무작위 정령은 사용 또는 교체가 확정된 뒤 대기열 끝에 추가한다.

## 정령 사용

활성 슬롯 `i`의 정령을 사용하면 다음 순서로 진행한다.

1. 선택한 정령의 공격과 모든 보드 효과를 계산한다.
2. 파괴한 특수 석판 효과를 처리한다.
3. 활성 슬롯 `i`를 대기 0으로 교체한다.
4. 대기 1·2를 한 칸 앞으로 이동한다.
5. 새 무작위 정령을 대기열 끝에 추가한다.
6. 갱신된 활성 정령 두 장의 자동 합성을 판정한다.

정령 사용은 소환 횟수를 1 증가시킨다. 축복 특수 석판을 파괴했다면 이 증가를
되돌려 결과적으로 소환 횟수를 소모하지 않는다.

## 정령 교체

활성 슬롯 `i`를 교체하면 카드 이동 자체는 정령 사용과 같다.

```text
선택한 활성 정령 제거
→ 대기 0이 해당 슬롯으로 이동
→ 대기열 전진
→ 끝에 새 무작위 정령 추가
→ 자동 합성 판정
```

차이점은 다음과 같다.

- 보드를 공격하지 않는다.
- 정령 소환 횟수를 사용하지 않는다.
- 정령 교체 가능 횟수를 1 사용한다.
- 교체된 기존 정령은 다른 위치로 돌아가지 않고 사라진다.

## 동일 정령 자동 합성

활성 정령 두 장의 `SpiritId`가 같으면 자동으로 합성을 시도한다.

### 기본 규칙

- 두 정령 중 레벨이 높은 쪽을 남긴다.
- 레벨이 같으면 기준 구현에서는 두 번째 활성 슬롯을 남긴다.
- 남기는 정령의 레벨을 1 올린다.
- 다른 정령은 소모하고 그 슬롯을 대기 0으로 채운다.
- 대기열을 전진시키고 새 무작위 정령을 끝에 추가한다.
- 새 활성 조합이 다시 같으면 합성을 반복한다.

```ts
function mergeSameSpirits(state: SpiritHand): SpiritHand {
  while (canMerge(state.active)) {
    const keepIndex = chooseHigherLevelCard(state.active);
    state.active[keepIndex].level += 1;
    state = replaceFromQueue(state, opposite(keepIndex));
  }
  return state;
}
```

### 레벨 조합

| 활성 조합 | 결과 |
|---|---|
| 1레벨 + 1레벨 | 한 장이 2레벨이 되고 다른 슬롯은 대기 0으로 교체 |
| 1레벨 + 2레벨 | 2레벨이 3레벨이 되고 1레벨 슬롯은 교체 |
| 2레벨 + 2레벨 | 한 장이 3레벨이 되고 다른 슬롯은 교체 |
| 3레벨 + 같은 정령 | 최고 레벨이므로 합성하지 않음 |
| 같은 신비 정령 2장 | 신비 정령은 강화 불가이므로 합성하지 않음 |

합성은 단순히 “같은 기본 카드 세 장으로 3레벨”만 허용하는 조합법이 아니다.
서로 다른 레벨의 동일 정령도 높은 쪽을 기준으로 한 단계 상승한다.

### 연쇄 합성 예시

```text
활성: 업화 1, 업화 1
대기: 업화 1, 해일 1, 정화 1

1차 합성
→ 활성: 업화 1, 업화 2
→ 대기: 해일 1, 정화 1, 새 정령

2차 합성
→ 활성: 해일 1, 업화 3
→ 대기: 정화 1, 새 정령, 새 정령
```

첫 합성으로 대기 0의 업화가 들어오면서 동일 정령이 다시 만들어져 자동으로
두 번째 합성이 실행된다.

## 특수 석판과 카드 갱신 순서

특수 석판 효과는 사용한 정령을 대기열 카드로 교체하기 전에 적용한다.

### 강화

```text
반대쪽 정령 레벨 +1
→ 사용한 슬롯을 대기 0으로 교체
→ 자동 합성 판정
```

- 반대쪽 정령이 최고 레벨이면 변화가 없다.
- 신비 정령도 강화되지 않는다.

### 복제

```text
반대쪽 정령을 사용한 정령의 종류·레벨로 복제
→ 사용한 슬롯을 대기 0으로 교체
→ 자동 합성 판정
```

복제 직후 사용한 원본 정령은 대기 0으로 교체되므로, 복제만으로 두 동일 정령이
활성 슬롯에 남아 자동 합성되는 것은 아니다. 새로 들어온 대기 0도 같은 정령일 때만
합성이 발생한다.

### 신비

```text
반대쪽 정령을 분출 또는 세계수의 공명으로 교체
→ 사용한 슬롯을 대기 0으로 교체
→ 자동 합성 판정
```

분출과 세계수의 공명은 최고 레벨이 1인 강화 불가 정령이다.

## 초기 카드 생성

게임을 시작할 때 일반 정령 풀에서 활성 2장과 대기 3장을 순서대로 생성한다.
초기 활성 카드가 같으면 플레이어가 첫 행동을 하기 전 자동 합성이 발생할 수 있으며,
대기 카드에 따라 연쇄 합성도 가능하다.

사람 대 AI 대전에서는 최초 5장을 양쪽에 동일하게 제공한다. 이후 사용·교체·합성으로
새 카드를 생성할 때에는 각 게임 인스턴스의 독립된 정령 난수 스트림을 사용한다.

## 엔진 명령과 이벤트

```ts
type SpiritCommand =
  | {
      type: "USE_SPIRIT";
      activeIndex: 0 | 1;
      target: Position;
    }
  | {
      type: "REROLL_SPIRIT";
      activeIndex: 0 | 1;
    };

type SpiritFlowEvent =
  | { type: "SPIRIT_USED"; activeIndex: 0 | 1; card: SpiritCard }
  | { type: "SPIRIT_REROLLED"; activeIndex: 0 | 1 }
  | { type: "QUEUE_ADVANCED"; revealed: SpiritCard }
  | {
      type: "SPIRITS_MERGED";
      consumedIndex: 0 | 1;
      resultIndex: 0 | 1;
      result: SpiritCard;
    };
```

합성 애니메이션은 `SPIRITS_MERGED` 이벤트마다 한 번씩 재생한다. 연쇄 합성이라도
엔진은 최종 결과만 반환하지 않고 모든 중간 이벤트를 순서대로 남긴다.

## 불변조건

```ts
type SpiritHandInvariant = {
  activeCount: 2;
  previewCount: 3;
  totalVisibleCount: 5;
  levelRange: 1 | 2 | 3;
};
```

- 카드 갱신이 끝나면 항상 활성 2장과 대기 3장을 유지한다.
- 정령 사용과 교체는 같은 `replaceFromQueue()` 함수를 사용한다.
- 카드 갱신이 끝난 뒤 합성 가능한 동일 정령이 남아 있으면 안 된다.
- 단, 최고 레벨 또는 강화 불가 정령끼리는 같은 종류로 남을 수 있다.

## 검증 상태

| 항목 | 상태 |
|---|---|
| 활성 정령 2장 | 인벤 화면·공략·구현 일치 |
| 대기 정령 3장 미리보기 | 인벤 화면·공략·구현 일치 |
| 사용한 슬롯에 대기 0 이동 | 공략 화면·구현 일치 |
| 교체 시 공격·소환 횟수 미소모 | 공략·구현 일치 |
| 교체 횟수 1 소모 | 게임 설명·구현 일치 |
| 동일 정령 자동 합성 | 인벤 자료·구현 일치 |
| 높은 레벨 정령을 남기는 합성 | 구현 확인, 영상 추가 검증 가능 |
| 동레벨에서 두 번째 슬롯을 남김 | 구현 세부사항, 게임 결과상 의미 없음 |
| 합성 후 연쇄 합성 | 구현 확인, 영상 추가 검증 가능 |
| 강화·복제·신비 후 카드 교체 순서 | 구현 확인, 영상 추가 검증 가능 |
| 신비 정령 강화 불가 | 인벤 자료·구현 일치 |
